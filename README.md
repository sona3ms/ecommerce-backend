# 🛒 Ecommerce Backend API

A RESTful Ecommerce Backend built using **Node.js**, **Express**, and **TypeScript**.

## ✨ Features

- REST API
- Product CRUD
- Swagger API Documentation
- Postman Collection
- TypeScript
- Express
- MVC Folder Structure

## 🛠 Tech Stack

- Node.js
- Express
- TypeScript
- Swagger UI
- Postman

## 📁 Project Structure

```text
src
├── controllers
├── routes
├── app.ts
├── server.ts
└── swagger.ts
```

## 🚀 Installation

```bash
git clone <repo-url>
cd ecommerce-backend
npm install
npm run dev
```

Server

```
http://localhost:3000
```

Swagger

```
http://localhost:3000/api-docs
```

## 📌 API Endpoints

| Method | Endpoint |
|---------|----------|
| GET | /home |
| GET | /products |
| GET | /products/:id |
| POST | /products |
| PUT | /products/:id |
| DELETE | /products/:id |
